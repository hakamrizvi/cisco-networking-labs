# Cisco Networking Labs

A collection of hands-on Cisco Packet Tracer networking projects focused on enterprise network design, routing, switching, network services, redundancy, security, and troubleshooting.

## Featured Project: Enterprise Network Design & Simulation

Designed and simulated a 45-device enterprise network using Cisco Packet Tracer.

### Network Infrastructure

| Device | Quantity |
|---|---:|a
| Routers | 12 |
| Multilayer Switches | 8 |
| Switches | 11 |
| Servers | 10 |
| Network Controllers | 2 |
| Wireless Access Points | 2 |
| **Total** | **45** |

### Technologies Implemented

**Routing**
- Static Routing
- OSPF
- Inter-VLAN Routing

**Switching**
- VLANs
- IEEE 802.1Q Trunking
- EtherChannel

**Network Services**
- DHCP
- DNS
- Syslog Server

**Network Security & Availability**
- Access Control Lists (ACLs)
- Hot Standby Router Protocol (HSRP)

**IP Networking**
- IPv4 Addressing
- Subnetting

### Network Testing

Used Cisco Packet Tracer simulation mode and network verification commands to inspect and troubleshoot network behavior.

### Project Files

The `enterprise-network/` directory contains the Packet Tracer project file and supporting documentation.

### Tools

- Cisco Packet Tracer
- Cisco IOS Command-Line Interface
- Packet Tracer Simulation Mode

## Learning Objectives

- Practice enterprise network architecture and configuration
- Understand routing and switching protocols
- Implement network redundancy and access controls
- Develop network troubleshooting skills
