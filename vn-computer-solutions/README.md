## Project Overview

This project presents a comprehensive network infrastructure design for **VN Computer Solutions & Training Academy**, a proposed four-floor organization with multiple departments, training facilities, centralized servers, and security systems.

The objective was to design a scalable, secure, manageable, and cost-effective network infrastructure capable of supporting business operations, training activities, communication, and future expansion.

The project was independently developed by **Hakam Rizvi** and includes network architecture selection, physical and logical topology planning, IP addressing, hardware requirements, security considerations, and network maintenance documentation.

## Network Architecture

### 1. Hybrid Network Topology

The proposed infrastructure combines two network topologies.

#### Star Topology

- Connects end-user devices to departmental access switches.
- Supports organized device connectivity and easier fault isolation.
- Accommodates computers, printers, wireless access points, IP cameras, and RFID devices.

#### Tree Topology

- Connects floor-level access switches to centralized core switches.
- Supports hierarchical network management.
- Allows infrastructure expansion across floors and departments.

### 2. Centralized Network Infrastructure

The design places the main network infrastructure on the second floor.

Key planned components include:

- Core switches and access switches
- Edge router and firewall
- Centralized server room
- Wireless access points
- PoE-enabled switching for supported devices
- CCTV and RFID access-control infrastructure

The design specifies **1 Gbps access connectivity** and **10 Gbps uplinks to the core layer**.

### 3. Three-Tier Client-Server Architecture

The selected architecture separates organizational services into three tiers.

| Tier | Responsibility |
|---|---|
| Presentation | End-user computers, laptops, and user interfaces |
| Application | Web services, authentication, and application processing |
| Data | Databases, file storage, and backup infrastructure |

This separation was selected to support centralized administration, security, maintainability, and future expansion.

## IP Addressing and Network Planning

The project includes an IP addressing strategy using **Variable Length Subnet Masking (VLSM)**.

The addressing plan was developed to:

- Allocate IP address ranges according to departmental requirements.
- Reduce unnecessary address allocation.
- Organize network segments.
- Support structured troubleshooting and future expansion.
